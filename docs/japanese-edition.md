# 日本語版 / 일본어판

- 한국어: `/balchik-imagination/`
- 일본어: `/balchik-imagination/ja/`
- 상단의 `한국어 / 日本語` 링크로 전환한다. 언어별 문서의 `lang`, 제목, 설명, `hreflang`을 설정했다.

## 생성 방식

`i18n/ja.json`은 한국어 원문과 일본어 번역의 대응표다. 번역 초안에는 공개 번역 서비스를 이용했고, `i18n/ja-overrides.json`에 제목·인명·금액 단위·통계 용어·인용 설명 등 수정한 표현을 기록했다. 인용문은 한국어 보도에서 일본어로 번역한 것임을 표시한다. 원자료 링크는 변경하지 않는다.

`node scripts/generate-japanese.mjs`가 공통 소스의 문자열·JSX 텍스트·템플릿 문구와 JSON의 설명 문구를 변환해 `src/ja/`에 일본어 엔트리를 생성한다. 생성물은 Git에 포함하지 않는다. 두 엔트리는 Vite의 다중 페이지 빌드로 함께 배포하며 React 등의 공통 코드는 공유 청크로 묶인다. 방문 시 번역 서비스나 LLM을 호출하지 않는다.

`dev`, `test`, `test:ui`, `build`에서 생성 단계를 실행한다. 새 번역 대상 문구가 누락되면 빌드를 중단한다. 새 모듈을 추가할 때는 생성 스크립트의 대상 목록도 갱신한다. 번역을 고칠 때는 사전 또는 override를 수정하고 생성한다. 통계값·결측치·ID·산식을 번역 사전으로 바꾸지 않는다.

## 검증

- 숫자 및 null 값 전체를 한국어판과 비교한다.
- GDP 기준연도 선택, 가격 비교, 합산 제조업 순위, 출처 창, 언어 전환을 PC·모바일에서 검사한다.
- 펼친 본문에 한국어가 남는지 검사한다. 언어 선택 링크의 `한국어` 표시는 예외다.
- 워ン/円, 位, 合計特殊出生率, 石破茂 등 핵심 표기를 별도로 검사한다.

주요 번역어: 발칙한 상상＝大胆な想像, 제조업 부가가치＝製造業の付加価値, 합계출산율＝合計特殊出生率, 원＝ウォン, 엔＝円. 한국어의 억·조는 일본어의 億·兆로 표기하며 환산하거나 수치를 바꾸지 않는다.

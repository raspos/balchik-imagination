# 메인 지도와 2024년 일본 설문 표시

2026-11-01 변경.

## 지도

Natural Earth 기반 datasets/geo-countries 경계에서 KOR·JPN을 추출한다. 기존 경제권 지도와 달리 위·경도 범위로 자르거나 국가별 화면 크기에 맞춰 확대하지 않는다. 모든 좌표에 중심 38°N·135°E, 반지름 6371.0088 km의 구면 Lambert 방위 등적 투영을 적용한다. 0.6 km 허용오차로 해안선을 단순화한다. 투영 평면의 면적 비율을 테스트하여 한국 약 10만 km², 일본 약 38만 km² 범위와 약 3.8배의 관계를 확인한다. 이는 지도 도형의 근사치이며 공식 측량 면적의 대체값이 아니다.

합치기 버튼은 동일 SVG 좌표계에서 국가 그룹을 평행 이동한다. 별도의 확대·축소·회전을 적용하지 않는다. 주요 육지 외곽이 처음 만나는 위치를 기준으로 배치하며 작은 도서가 겹칠 수 있다. 점선 잔상은 원래 위치다. 이 시각화는 가상 배치이며 현실의 국경 변경을 제안하거나 예측하지 않는다.

- 경계: https://github.com/datasets/geo-countries
- 투영: https://proj.org/en/stable/operations/projections/laea.html
- 국가 면적 참고: https://data.worldbank.org/indicator/AG.SRF.TOTL.K2?locations=KR-JP

## 호감도

원본 `surveys.json`의 2024년 일본 값은 null(미조사)로 유지한다. 사용자의 요청에 따라 표시 계층에서만 2023년 값을 2024년에 유지한다. 2023→2024→2025 연결 구간은 점선이고 2024년 점은 빈 원이다. 좋은 인상·좋지 않은 인상 모두 동일하게 적용한다. 선택 연도 수치에는 ‘전년도 유지’를 병기하고 데이터 표에는 ‘미실시’를 유지한다. 보간·관측값·2024년 실제 설문 결과로 취급하지 않는다.

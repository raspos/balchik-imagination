# 구현·검증 보고

## 기존 프로젝트

작업 디렉터리의 파일·package.json·AGENTS.md와 `발칙한 상상` 문자열을 검색했다. 관련 기존 프로젝트가 발견되지 않아 별도 `balchik-imagination`을 생성했다. 다른 프로젝트 소스는 수정하지 않았다.

## 구현과 검증

요청한 10개 화면과 주요 인터랙션을 구현했다. 데이터와 해석, 공식 수치와 기관 전망, 보도 확인과 원자료 확보, 경제공동체와 국가 가정을 구분했다. 데이터 수집·파생·논리 검사·브라우저 검증 스크립트, GitHub Pages Actions, 실행·배포·갱신 문서를 포함한다.

원자료 수집: IMF, UN WPP의 OWID 배포, WB, EAI 원도표와 장기 도표. SIPRI 공식 PDF·정치인/기업인 보도·EU와 해외 사례·출판사 서지를 열람했다. 상세 출처와 한계는 sources.md, methodology.md 및 앱 출처 패널에 있다.

검증 수치는 이 저장소에 고정된 스냅샷 기준이다. IMF와 UN의 직접 원본 판본까지 일치하는지 추가 대조가 필요하므로 언론사 출고가 완료됐다고 주장하지 않는다.

## 확보하지 못한 것

- 대한상의 원 설문지와 표본 설계, 과거 여론조사 연도별 전체 방법론
- 경제·안보협력에 대한 전체 연도 시계열
- 품목별 수출입 구조와 기업 공시 기반 점유율
- 직접 원어 발언록·영상, 더 넓은 정치인·기업인 아카이브
- 계량모형에 따른 성장효과, 정치통합 지지율, 통합 지휘체계의 방위력

미확보 값은 빈 상태·한계로 공개했다. 위 항목은 완성된 것처럼 표현하지 않는다.

## 실행·배포

`npm ci`, `npm run dev`. 배포 파일은 `npm run build`의 `dist/`. GitHub Pages는 저장소 루트로 올린 뒤 Pages Source를 GitHub Actions로 지정한다. 원격 GitHub 저장소 생성·공개 배포는 미수행. 미리보기용 비공개 Sites 배포는 별도 경로로 진행하며 최종 응답의 성공 URL을 기준으로 한다.

## 확장

원 설문지와 마이크로데이터 기반 세대·여행 경험 분석, HS 품목별 의존과 공급망 분석, RCEP 대비 추가 개방, 문헌 기반 효과 모형·민감도 분석, 원어 발언 아카이브 확장. 데이터 근거와 연구 설계 없이 자동으로 효과 수치를 생성하지 않는다.

## 2차 개편 결과

사용자 편집 방향에 따라 11개 섹션으로 재배열했습니다. 메인 제목을 질문 자체로 바꾸고, 한일 대조 실루엣·전환·숫자 카운트·스크롤 등장 효과를 추가했습니다. 본문 16~18px 이상을 기준으로 키우고 심화 설명을 접었습니다. 발언·배경, 규모, 생활 차이, 현실·여론, EU, 현실화 조건을 순차적으로 탐색합니다. 추가 비교는 자동차·84㎡ 주거 참고·최저임금·지하철·물가 PPP·고령화·출산율·기대수명·반도체·R&D·정부부채·1인당GDP·대학 13개입니다. 교차환율과 통화바스켓은 계산식·단위·가상성을 명시합니다. 실제 주택 동등가격과 새 통화의 미래 시장환율을 예측한 것은 아닙니다.

# 발칙한 상상

**한국과 일본이 하나의 나라가 된다면?** 실제 통계, 여론조사, 유럽통합 역사로 탐색하는 React + TypeScript + Vite 정적 인터랙티브 사이트. 방문자 API 키·유료 API·LLM 호출·서버 DB가 필요하지 않습니다.

## 실행

Node.js 22 이상 권장. 프로젝트 디렉터리에서:

```sh
npm ci
npm run dev
npm test
npm run build
```

`dist/`를 정적 호스팅에 올리면 됩니다. 상대경로 base를 사용하므로 GitHub Pages 저장소 하위 경로도 지원합니다. 폰트는 Google Fonts를 요청하며 연결되지 않으면 시스템 글꼴로 동작합니다. 숫자·지도·차트 데이터는 번들 또는 정적 파일로 제공하므로 실행 중 원 통계 서버를 조회하지 않습니다.

## 구현

- 11개 섹션, 고정 목차·모바일 메뉴·반응형 레이아웃·키보드 조작·동작 줄이기 설정
- 실제 해안선 지도와 국가별 인구 선택, GDP·인구·군사비 합산 팩트체크, 연도·지표 변경
- EU 12개 사건: 실제 제도 변화 / 갈등 / 한일에 필요한 조건
- 2013~2026 상호인식 선형 차트·연도 탐색·비호감 전환·정확한 수치표, 2024 일본 결측 유지
- 경제공동체 조사·여행 경험 비교·7단계 수용성 사다리
- 5개 통합 수준·5개 의결 규칙·양국 투표·특정 분야 거부권·3개 통화제도 실험
- GDP·PPP·부채·고령화·수출입·R&D·1인당 GDP, 8개 산업의 쟁점 탐색
- 날짜·맥락·원문 확보 여부를 구분한 3개 발언/발표 기록, 분야·날짜 정렬
- 해외 사례 7개, 학술·정책 연구 8개, 필터·검색
- 출처 패널(기관·URL·발표/수집일·단위·분모·방법·산식·한계), 데이터 JSON 다운로드

## 확인한 데이터와 주요 결과

수집 기준일: **2026-10-31 (한국 시간)**.

| 데이터 | 기준 | 처리 |
|---|---|---|
| IMF DataMapper NGDPD | 2024/2025/2026 | 국가·경제 코드만 교집합, 지역 집계 제외. 2026 전망. API 판본 메타데이터 미확보 |
| UN WPP 2024 / OWID 가공 배포 | 2024년 중위 전망 | 한국 51,717,587 + 일본 123,753,041 = 175,470,628명. 가상 합계 **8위** |
| SIPRI 공식 2025 인포그래픽 | 2025 | 한국 47.8 + 일본 62.2 = 110.0십억 달러. 지출 규모 **5위**, 방위력 아님 |
| EAI·겐론NPO / API·KEI / IHJ | 확보 연도 2013~2026 | 기관·방법 변경과 2024 일본 미실시 주석. 2026 호감 한국 54.3%, 일본 35.3% |
| 대한상의·한국리서치 / 연합뉴스 확인 | 2026-07-07 | 양국 각 500명. 경제공동체 긍정 69.8%·59.8%. 원 설문지는 미확보 |
| World Bank WDI | 무역·1인당·고령화 2024 / R&D 2023 | 같은 연도로 맞춤. 2024 R&D는 결측이므로 비공개 대체 추정하지 않음 |

GDP는 해당 스냅샷에서 2024년 합계 6.088407조 달러, 가상 합계 3위입니다. **경제공동체가 국가가 되는 것은 아닙니다.** 단일국가 가정에서만 국가 순위라고 표현하며 다른 시나리오는 규모 참고치입니다. 정치인의 발언 자체와 통계 검증 결과는 다릅니다.

## 재현·갱신

```sh
npm run data:collect
npm run data:build
npm test
npm run data:links
npm run build
```

- 자동 수집은 데이터 API와 UN 원자료의 OWID 배포본을 다운로드합니다. 네트워크가 필요합니다. 모든 실패는 collection-log 또는 실행 오류로 확인합니다.
- `scripts/derive.mjs`는 고정된 원본에서 합산·순위·지도 클리핑을 재현합니다. 원본을 갱신하면 과거값도 개정될 수 있으므로 이전 스냅샷을 별도 보관하고 차이를 검토해야 합니다.
- EAI 도표는 원본 이미지에서 사람이 전사·대조했습니다. `src/data/surveys.json`을 자동 최신값으로 바꾸지 않습니다. 조사 원문·표본을 검토한 후 수동 갱신하세요.
- `scripts/research.mjs`는 EAI 2026 공개 도표를 검증용 `docs/raw/`에 수집합니다. 해당 이미지들은 웹 배포물에 포함하지 않습니다.
- API 응답·CSV·전사 원본과 수집 경로는 `docs/sources.md`, 계산 규칙은 `docs/methodology.md`를 참고하세요.

## 검증

```sh
npx playwright install chromium
npm run test:ui
```

기존 Chromium 실행 파일을 쓰려면 환경변수 `PW_EXECUTABLE_PATH`를 지정하세요. Windows PowerShell 예:

```powershell
$env:PW_EXECUTABLE_PATH='C:\path\to\chrome.exe'
npm run test:ui
```

논리 테스트 6건은 환율 교차환산·가상 통화 단위 및 합계 순위에서 양국 중복 제거, 결측 실패 처리, 인구 순위, 표결 비대칭과 거부권, 결측 선 분리를 검증합니다. 브라우저 테스트는 PC 1440×1000·모바일 390×844에서 주요 조작과 가로 넘침·런타임 오류를 검사합니다. 스크린샷은 `docs/*-hero.png`, `docs/*-lab.png`입니다.

## GitHub Pages 배포

1. **이 디렉터리 자체를 저장소 루트로** GitHub에 올립니다. 부모 디렉터리의 다른 프로젝트를 올리지 마세요.
2. 저장소 Settings → Pages → Source를 **GitHub Actions**로 선택합니다.
3. 기본 브랜치 `main`에 push하거나 `Deploy GitHub Pages` 워크플로를 수동 실행합니다.
4. Actions가 `npm ci` → 논리 테스트 → 빌드 → Pages 배포를 수행합니다.

설정 파일: `.github/workflows/pages.yml`. 별도 GitHub 저장소 생성·공개 Pages 배포는 수행하지 않았습니다. 사이트 미리보기용 비공개 Sites 배포와는 별개의 배포 경로입니다.

## 미확보·출고 전 확인

현재는 **실제 동작하는 조사·시뮬레이션 구현본**이며 모든 보도 데이터가 완결된 출고 승인본은 아닙니다.

- IMF 원본 WEO 판본·발표일 및 개별 계열 실적/추정 메타데이터를 고정 파일과 추가 대조해야 합니다.
- UN 서버 직접 원본과 OWID 가공 배포본을 추가 교차검증할 수 있습니다. 2024 인구는 전망임을 유지합니다.
- 2013~2024 조사의 연도별 전체 표본·방법, 경제·안보협력 장기 시계열, 대한상의 원 설문지를 미확보했습니다.
- 품목별 무역 구조·기업별 공시·시장점유율·통합 계량모형은 없습니다. 산업 설명은 편집상 제도 분석입니다.
- 연방국가·공동통화 지지율, 성장 효과, 지휘체계 통합 후 방위력은 추정하지 않았습니다.
- DOI 링크 일부와 EU 등 공식 사이트가 자동 클라이언트에 403/WAF를 반환했습니다. 웹 검색·열람으로 확인한 내용과 HTTP 접근 결과를 `docs/link-check.json`과 `docs/sources.md`에 구분했습니다.
- 언론사 상업 서비스 전 SIPRI 사용조건과 인용 권리 확인이 필요합니다.

확장 방향: 원 설문지·마이크로데이터 기반 세대 분석, HS 품목별 상호의존도, RCEP 대비 추가 개방 시나리오, 문헌 기반 계량모형과 민감도 분석. 근거를 확보하기 전 수치는 추가하지 않습니다.

## 2차 개편

큰 제목·대비 그래픽과 전환/숫자/스크롤 효과를 적용하고 발언→규모→생활비→현실·여론→EU→전망의 이야기 순서로 재구성했습니다. 심화 내용은 접어서 볼 수 있습니다. 생활비·사회·산업·교육 13개 비교와 ECB 기준 새 통화 바스켓 실험을 추가했습니다. [추가 자료와 계산](docs/comparisons.md) 참고.
